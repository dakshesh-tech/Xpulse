⚡ XPulse — Level Up Your Real Life

«Turn your everyday life into an RPG. Complete quests, earn XP, unlock achievements, and become the main character of your own journey.»

XPulse is an AI-powered real-life RPG that transforms everyday activities, personal goals, and responsibilities into an interactive gaming experience.

Instead of simply maintaining a to-do list, XPulse lets you describe what you accomplish and uses AI to turn your real-world progress into quests, experience points, character progression, and achievements.

🎮 The Concept

What if improving yourself felt like playing an RPG?

XPulse brings game mechanics into everyday life. Your studies, workouts, projects, habits, and personal challenges become opportunities to earn XP and develop your character.

You are the player. Your real life is the game. AI is your Game Master.

✨ Features

🤖 AI-Powered Quest Generation

- Describe a task or goal in natural language.
- AI converts your description into structured RPG-style quests.
- Quests can include objectives, difficulty, rewards, and progression.
- AI adapts quests to your real-life activities and goals.

⚔️ Character Progression

Develop your character by completing real-world activities.

Character attributes include:

- 🧠 Intelligence
- 💪 Strength
- 🎯 Discipline
- 🎨 Creativity
- 🦉 Wisdom

Earn XP, progress through levels, and watch your character evolve.

🏆 Dynamic Achievement System

- Unlock badges for reaching milestones.
- Earn achievements for consistency and personal growth.
- Celebrate exceptional accomplishments.
- Discover new achievements as you progress.

📖 AI Game Master

Your AI Game Master helps transform everyday experiences into meaningful game progression.

- Record what you accomplished.
- Interpret your activities.
- Generate appropriate rewards and progression.
- Turn ordinary achievements into memorable milestones.

📊 Progress Tracking

Track your journey through your character's progression, XP, attributes, quests, and achievements.

🔄 AI Model Fallback System

Designed with AI availability and reliability in mind.

- OpenRouter integration for accessing multiple AI models.
- Support for configurable model providers.
- Fallback architecture to help process tasks when a preferred model becomes unavailable or reaches its limits.
- Gemini API integration.

🚀 Getting Started

Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

1. Clone the repository

git clone https://github.com/dakshesh-tech/Xpulse.git

2. Navigate to the project

cd Xpulse

3. Install dependencies

npm install

4. Configure environment variables

Create a ".env" file in the root directory.

Use ".env.example" as your reference.

FREE_ONLY_MODE=

OPENROUTER_API_KEY=
OPENROUTER_BASE_URL=

APP_URL=

GEMINI_API_KEY=

Add the appropriate API keys and configuration values.

Important: Never commit your ".env" file or expose API keys in frontend code or public repositories.

5. Start the development server

npm run dev

The application will start in development mode.

🔐 Security

- Store API keys in environment variables.
- Keep AI provider credentials on the server.
- Never expose private credentials in client-side code.
- Configure Firebase authentication and authorized domains appropriately.
